🚀 Installation

Schritt 1: Projekt Clone & Setup

cd /data/.openclaw/workspace/runwayhub
composer install
cp .env.example .env
php artisan key:generate

Schritt 2: Datenbank Konfiguration

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=runwayhub_db
DB_USERNAME=root
DB_PASSWORD=***

Schritt 3 & 4:

php artisan migrate --seed
php artisan serve
# Besuche http://localhost:8000 im Browser
